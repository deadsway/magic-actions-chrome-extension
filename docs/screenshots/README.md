# Screenshot checklist

Add exactly these two screenshots for the main repository README:

1. `options.png`
   - Open the magic-actions Options page.
   - Show the redesigned colour palette, typography, controls, and several settings.
   - Recommended size: about 1200 × 800 px.

2. `player-toolbar.png`
   - Open a normal YouTube video.
   - Open the magic-actions in-player toolbar.
   - Keep enough of the video player visible to show where the toolbar is integrated.
   - Recommended size: about 1600 × 900 px.
   - Avoid personal account information or unrelated browser UI where possible.

After adding both images, uncomment the two Markdown image lines in the root `README.md`.
